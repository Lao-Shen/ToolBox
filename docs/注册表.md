# 注册表速查：鼠标右键菜单

## 一、右键菜单的注册表位置

| 右键对象 | 注册表位置 | 说明 |
|---|---|---|
| 所有文件 | `HKEY_CLASSES_ROOT\*\shell\` | 对任意文件生效 |
| 某类文件 | `HKEY_CLASSES_ROOT\<文件类型名>\shell\` | 如 `.txt` 用 `txtfile` |
| 文件夹本身 | `HKEY_CLASSES_ROOT\Folder\shell\` | 对文件夹右键 |
| 文件夹空白处 | `HKEY_CLASSES_ROOT\Directory\Background\shell\` | 桌面、文件夹内空白区右键 |
| 磁盘/驱动器 | `HKEY_CLASSES_ROOT\Drive\shell\` | 对盘符右键 |
| 文件关联打开方式 | `HKEY_CLASSES_ROOT\<文件类型名>\OpenWithList\` | 右键“打开方式”列表 |

### 关键说明
- `HKCR`（HKEY_CLASSES_ROOT）是 **HKCU\Software\Classes** 与 **HKLM\Software\Classes** 的合并视图，**HKCU 优先**。
- 新增/修改右键项建议写到 `HKEY_CURRENT_USER\Software\Classes\...`（免管理员权限），效果与写 HKCR 相同。
- Win11 新版右键菜单（精简菜单）数据在 `HKEY_CURRENT_USER\Software\Classes\Local Settings\Software\Microsoft\Windows\CurrentVersion\Shell Extensions\Blocked` 等键；第三方通过 `shell\` 添加的项默认被折叠到“显示更多选项”，需用 `ShowCopypasteMenu`、`NoChangeWindow` 等策略或工具强制显示经典菜单。

## 二、菜单项（verb）下的字段

在 `<位置>\shell\<菜单名>\` 下可设置：

| 值名 | 值类型 | 作用 |
|---|---|---|
| `(默认)` | REG_SZ | 菜单显示的名称（留空则显示“打开”） |
| `MUIVerb` | REG_SZ | 本地化显示名称，优先级高于默认值 |
| `Icon` | REG_SZ | 菜单项图标，格式：`路径,索引`（如 `notepad.exe,0`） |
| `Extended` | 无值 | 存在此值时仅按住 **Shift** 右键才显示 |
| `Position` | REG_SZ | 菜单位置（`Top`/`Bottom`，或文件名） |
| `SubCommands` | REG_SZ | 指向 `shell\菜单名\command` 下的级联子菜单 |
| `HasLUAShield` | 无值 | 菜单项显示 UAC 盾牌图标 |
| `NoWorkingDirectory` | 无值 | 不设置工作目录 |
| `command` | 子键 | 具体执行的命令（见下） |

## 三、command 子键字段

`shell\<菜单名>\command\` 下的值：

| 值名 | 值类型 | 作用 |
|---|---|---|
| `(默认)` | REG_SZ | 要执行的命令行，可用 `%1`（文件）、`%V`（目录）等占位符 |
| `DelegateExecute` | REG_SZ | COM 处理程序 CLSID，优先于默认命令行；配置用 `%SystemRoot%\System32\shell32.dll` |
| `verb` | REG_SZ | 动词名（如 `open`、`edit`），供编程调用 |

### 占位符示例
- `notepad.exe "%1"` —— 用记事本打开文件
- `cmd.exe /k cd /d "%V"` —— 在文件夹打开命令提示符
- `powershell.exe -NoExit -Command "Set-Location -LiteralPath '%V'"` —— 在文件夹打开 PowerShell

## 四、级联子菜单

```
shell\MyMenu\              → (默认)=父菜单名
shell\MyMenu\SubCommands\  → 设置项，值为子项 CLSID 或直接列子项
shell\MyMenu\shell\Item1\command\ → (默认)=cmd /c ...
shell\MyMenu\shell\Item2\command\ → (默认)=cmd /c ...
```

子项同样支持上面的 MUIVerb、Icon、Extended 等字段。

## 五、新建菜单（右键“新建”）

| 位置 | 说明 |
|---|---|
| `HKEY_CLASSES_ROOT\<扩展名>\ShellNew` | 定义某类型文件的“新建”入口 |
| `HKEY_CLASSES_ROOT\.txt\ShellNew` | 示例：右键“新建”→“文本文档” |

### ShellNew 字段
- `NullFile`（REG_SZ）—— 创建空文件
- `FileName`（REG_SZ）—— 从模板复制（指向 `%SystemRoot%\ShellNew\` 下的文件）
- `Data`（REG_BINARY）—— 写入的二进制内容
- `ItemName`（REG_SZ）—— 菜单显示名（默认用文件类型描述）
